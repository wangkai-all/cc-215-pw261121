# 零售价格指数核对工具（虚构数据演示）

一个**从零实现的本地 Web 工具**，用于核对零售商品篮子、按公开规则计算价格指数并追溯每个篮子条目的原始报价。

> **免责声明**：本工具使用**完全虚构**的零售数据，指数编制规则为教学化简版本，**不复刻、不代表任何官方零售价格指数**（如国家统计局 RPI/CPI）。计算结果不构成任何统计或决策依据。

## 运行

```bash
# 任选其一启动本地服务（ES Module 需要 http 协议）
npm start                    # = python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 运行测试（Node 18+，无第三方依赖）
npm test

# 重新生成样例数据
npm run gen-sample
```

## 功能页签

| 页签 | 内容 |
|---|---|
| 数据导入 | 加载内置样例，或导入 `dataset.json` / 一组 CSV；自动识别表头并做一致性校验 |
| 篮子核对 | 篮子条目、规格链、可比单位价、基期权重、处理标记；替代关系勾选启用；处理披露逐条列示 |
| 指数计算 | 选择**基期**、**权重方案**、固定篮子/链式；指数曲线、统计块、数据表；保存修订版本 |
| 贡献分解 | 各条目对指数的贡献（指数点）；销售额变化分解为价格效应 / 结构效应 / 交互效应 |
| 报价追溯 | 每个篮子条目的入指数序列与**门店原始报价明细**（原始价、促销/缺货状态、估算方式、销量） |
| 不可比与覆盖 | 无法衔接的条目单列（原因、起始期、权重份额）；逐期覆盖率 |
| 版本与公式 | 修订版本保存与两两对比；全部计算公式；处理规则 R1–R6；免责声明 |

## 处理规则（公开规则，版本 1.0.0）

- **R1 可比计量单位换算**：所有报价先按商品规格换算为可比计量单位价格（元/100ml、元/kg、元/500g 等），规格不同的商品按单位价格比较。
- **R2 促销价处理**：促销报价不直接作为常规价格计入指数；该期常规价按 R3 估算，促销报价与处理方式**逐条披露**——不允许不说明地用促销价替换常规价。
- **R3 缺价/缺货估算**：① 同期其他门店常规价均值；② 相邻已知常规价线性插值；③ 沿用最近常规价（同一序列最多连续 2 期）。全部估算逐条披露。
- **R4 退市处理**：退市且无启用的替代品时，沿用最近常规价最多 2 期，之后列为**不可比项目**并反映到覆盖率。
- **R5 新品替代衔接**：规格变化（spec-change）与同质同规格（equivalent）按可比单位价格直接衔接；不可直接比较（non-comparable-overlap）按重叠期单位价格比 `k=旧/新` 缩放新品序列衔接；无重叠期报价则列为不可比。
- **R6 门店更替**：门店关闭/替换时，由指定接替门店自更替期起承接原门店的报价序列与权重，更替逐条披露。

## 计算公式

- 单位价 = 售价 ÷（规格量 × 换算系数）
- 固定篮子拉氏：`I_L(t) = Σ w_i0·(p_it/p_i0) / Σ w_i0`，`w_i0 = p_i0·q_i0`（基期支出，可比单位口径）
- 帕氏：`I_P(t) = Σ p_it·q_it / Σ p_i0·q_it`；费雪：`I_F = √(I_L × I_P)`
- 链式：`I(t) = I(t−1) × link(t)`，link 为相邻两期可比条目的环比（拉氏/帕氏/费雪），基期 = 100，向前后两个方向链接
- 条目贡献：`c_i(t) = (w_i0/Σw) × (p_it/p_i0 − 1) × 100`（指数点），`Σc_i = I_L − 100`
- 价值分解：`ΔV = Σ(p_t−p_0)q_0`（价格效应）`+ Σ(q_t−q_0)p_0`（结构效应）`+ Σ(p_t−p_0)(q_t−q_0)`（交互效应）
- 覆盖率 = 当期可比条目权重和 ÷ 篮子总权重

权重方案：基期支出（拉氏）/ 报告期数量（帕氏）/ 费雪理想 / 自定义权重（拉氏型，页面可编辑）。

## 样例数据覆盖的场景（全部虚构）

| 场景 | 商品/门店 | 规则 |
|---|---|---|
| 规格缩小 | 酸奶 100g×8 → 90g×8（P02→P03，包装价不变，单位价 +11%） | R1+R5 |
| 促销跨期 | 薯片 3–4 月连续促销、11 月单月促销（P04） | R2+R3 |
| 缺货 | 洗衣液城西店 2025-08 缺货（P05/S2） | R3 |
| 门店更替 | 城南老店 6 月末关闭，新店 7 月承接（S3→S5） | R6 |
| 退市无替代 | 进口饼干 5 月末退市（P08） | R4 |
| 重叠衔接替代 | 洗发水换品牌（P09→P10，2025-09 重叠期） | R5 |

## 数据格式

`dataset.json` 字段：`meta.periods`（YYYY-MM）、`products`（id/name/categoryId/specQty/specUnit/baseUnit/onShelf/offShelf）、`stores`（id/name/region/openPeriod/closePeriod）、`quotes`（productId/storeId/period/price/qty/promo/stockout）、`basket`（productId/weight 可空）、`substitutions`（id/from/to/type/switchPeriod/overlapPeriod/note）、`storeReplacements`（from/to/period/note）。CSV 分文件格式见 `sample-data/*.csv` 表头，导入时按表头自动识别。

## 代码结构

```
index.html          页面骨架（七个页签）
css/style.css       样式（亮/暗两套调色板，CSS 变量）
js/engine.js        计算引擎（纯函数：换算、估算、衔接、指数、分解、覆盖率）

js/csv.js           CSV 解析
js/charts.js        内联 SVG 图表（折线/堆叠柱/正负条形，含提示框与键盘可达）
js/app.js           页面装配与状态
js/sample-data.js   生成的样例数据（ESM）
scripts/gen-sample.mjs  样例数据生成脚本
tests/              Node 内置 test runner 单元测试（60+ 项）
sample-data/        样例 CSV + JSON
```

可视化遵循 dataviz 规范：分类色取参考调色板 1–3 号位（已用 dataviz 技能的调色板校验脚本验证亮/暗两模式；亮模式 aqua 对比度 WARN 由图例+提示框+数据表缓解），文字一律文本色，图表均配数据表。

## 修订版本

每次在"指数计算"页点击"保存为版本"，会以 `v1, v2, …` 记录完整配置（基期、权重方案、自定义权重、启用的替代关系）、规则版本号（当前 1.0.0）与指数结果，保存在浏览器 localStorage，可在"版本与公式"页两两对比。规则或公式变更时应提升 `js/engine.js` 中的 `RULES_VERSION`。
